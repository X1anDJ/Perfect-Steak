# Perfect-Steak

This is an app for calculating the steak's heat transfer behavior in a electric stove. 
It uses Crank-Nicolson method https://en.wikipedia.org/wiki/Crank%E2%80%93Nicolson_method#Example:_1D_diffusion_with_advection_for_steady_flow,_with_multiple_channel_connections in solving the one dimension heat equation 

∂T(x, t) / ∂t = α ∇²T(x, t).
